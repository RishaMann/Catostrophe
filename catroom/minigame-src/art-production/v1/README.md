# Catostrophe minigame — art pack v1

Первый визуальный проход для вертикальной мини-игры с прыжками кота.
Пакет пока не подключён к игровому коду и не заменяет greybox автоматически.

## Структура

- `masters/` — полноразмерные исходники генерации.
- `runtime-1x/` — файлы точного размера для текущего Phaser-кода (поле 540×960).
- `runtime-2x/` — ретина-версии для поля 1080×1920. Для них код должен явно задавать display size.
- `storyboard-frames/` — 12 отдельных ключевых поз сиамского кота.
- `scene-preview-1x.jpg` — проверочный композит в базовой раскладке уровня.
- `screen-layout-preview-1x.jpg` — проверочный макет экрана с шапкой, комнатой и нижней лентой.

## Фон

`background.png` содержит только неподвижную архитектуру: потолок, стену,
плинтус и деревянный пол. Все объекты, которые зеркалятся, сдвигаются или
участвуют в физике, остаются отдельными PNG.

Все предметные спрайты в `masters/`, `runtime-1x/` и `runtime-2x/` сохраняются
как RGBA PNG с настоящей прозрачностью, без чёрного фона и шахматной сетки.

## Зоны игрового экрана

Базовый экран 540×960 разделён на три независимых слоя:

| Зона | Координаты 1× | Размер 1× | Ассет |
| --- | --- | --- | --- |
| Шапка задания | `y: 0–111` | 540×112 | `hud-header.png` |
| Комната | `y: 112–904` | 540×793 | отдельный viewport фонового слоя |
| Сообщения / подсказки / реклама | `y: 905–959` | 540×55 | `hud-footer.png` |

`hud-header.png` и `hud-footer.png` не содержат текста. Текст задания,
прогресс, число рыбок, подсказки управления и рекламный материал должны
рисоваться кодом поверх панелей. Нижняя панель — единая область для уже
существующего рекламно-подсказочного блока.

Нижняя панель накладывается на нижнюю половину ковра высотой 110 px. Верхняя
половина ковра остаётся видимой частью игрового поля и сохраняет опорную
кромку для кота и предметов.

При интеграции комната должна оставаться отдельным world-layer: UI не входит
в физические координаты и не масштабирует предметы. Камера игрового мира
ограничивается средней зоной, а HUD закрепляется через `scrollFactor: 0`.

## Раскадровка кота

Кадры идут слева направо и сверху вниз:

1. Спокойная стойка.
2. Прижимается перед прыжком.
3. Отталкивание.
4. Набор высоты.
5. Верхняя точка.
6. Падение.
7. Приземление со сжатием.
8. Скольжение после приземления.
9. Ходьба.
10. Висит на люстре одной лапой.
11. Мокрый после аквариума.
12. Получает подушкой и кувыркается.

`cat.png` собран из кадра 1, `cat-hang.png` — из кадра 10.

## Перед подключением

1. Текущий код использует натуральный размер текстуры, поэтому без изменений
   подключается папка `runtime-1x`. Комментарий про загрузку файлов ×2 в
   `src/config/assets.js` пока не соответствует фактическому рендерингу.
2. Для `runtime-2x` нужно после создания каждого изображения задавать
   `setDisplaySize(ASSETS[key].w, ASSETS[key].h)` и отдельно проверить физические тела.
3. В `assets.js` пока нет ключа `tv`: падающий телевизор имитируется текстурой
   подушки с тонировкой. Его нужно выделить в отдельный ассет.
4. Фон пока не загружается реестром и потребует отдельного ключа/слоя глубины.
5. Код кота знает только `cat` и `cat_hang`. Для полной анимации потребуется
   атлас или последовательности кадров для состояний прыжка, приземления,
   ходьбы, воды и попадания подушкой.
