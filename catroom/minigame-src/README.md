# Кот — скелет игры

Greybox-версия: механика работает, вместо графики — подписанные прямоугольники.

## Как запустить у себя

```bash
npm install
npm run dev
```
Открыть адрес, который покажет консоль (обычно http://localhost:5173).
Чтобы проверить с телефона — в консоли будет второй адрес вида
http://192.168.x.x:5173, открывать его с телефона в той же Wi-Fi сети.

## Как выложить

```bash
npm run deploy
```

## Что где лежит

```
src/
  main.js                точка входа: настройка игры и список сцен
  config/
    assets.js            РЕЕСТР АССЕТОВ — договор между кодом и графикой
    level.js             что стоит в комнате, где, что кот говорит
    tasks.js             пул заданий
    balance.js           все числа игры
  core/
    greybox.js           рисует заглушки, пока картинок нет
    save.js              сохранение в браузере
  scenes/
    MenuScene.js         три задания на сегодня
    LevelScene.js        уровень: прыжки
    ResultScene.js       итог захода
public/
  art/                   сюда художник кладёт картинки
```

## Правило, ради которого всё так разложено

**Данные отдельно от кода.**
Чтобы добавить предмет, поменять реплику, цену или награду — правится файл
в `config/`. Файлы в `scenes/` при этом не трогаются вообще.

## Как подключить графику

1. Художник смотрит в `src/config/assets.js` и рисует картинку **в точно
   указанном там размере**.
2. Кладёт файл в `public/art/` под именем из поля `file`.
3. Дописывает ключ в массив `READY` в конце `assets.js`.
4. Всё. Заглушка и подпись пропадают сами, появляется картинка.

Поле игры — 400 × 700 пикселей, вертикальное. Оно масштабируется
под любой экран целиком, поэтому рисовать надо именно в этих координатах.
