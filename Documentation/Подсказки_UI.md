# Подсказки по интерфейсу — план и текст

Черновик для будущей задачи: показать игроку короткие подсказки о том, как
пользоваться интерфейсом игры (`catroom/`). Здесь — готовый текст (можно
брать и вставлять в реализацию) и план, как это встроить, не решая заранее
вопросов, которые не были поставлены.

## Готовый текст (15 подсказок)

Без раздела «Настройки» — по условию задачи. Порядок — от общего
(расстановка/еда) к частному (гэги, персонаж, полноэкранный режим).

1. Для размещения предмета откройте меню «Инвентарь» и перетащите его на пол.
2. Для взаимодействия с уже стоящим предметом (погладить кота, включить свет) закройте «Инвентарь».
3. Для перестановки уже стоящего предмета откройте «Инвентарь», возьмите предмет и перетащите на новое место или обратно в список.
4. Для кормления кота или игры с ним откройте «Корм» и перетащите еду или игрушку к коту, миске или на пол.
5. Для закрытия списка «Инвентарь»/«Корм» нажмите «× закрыть» в правом верхнем углу панели.
6. Если предметов в списке больше одной страницы, листайте стрелками ‹ › или свайпом по панели.
7. Чтобы погладить кота, тапните по нему — так поднимается настроение.
8. Чтобы кот пошёл в нужное место, тапните по полу.
9. Для переноса двери, окна или точки крепления света откройте «Инвентарь» и перетащите их вдоль стены.
10. Для включения и выключения света тапните по выключателю у двери или по подставке торшера — это работает в любом режиме.
11. Некоторые предметы реагируют на тап в обычном режиме: штора открывается и задёргивается, коробка меняет вид, портрет падает и возвращается на место.
12. Для смены персонажа откройте панель с именем кота, выберите нового в списке и нажмите «Выбрать».
13. Разделы «Задания» и «Магазин» пока недоступны — содержимое появится позже.
14. Для полноэкранного режима нажмите на значок в правом верхнем углу экрана.
15. Если место для предмета не подходит, игра покажет причину прямо над ним.

Термины и написание кнопок сверены с `catroom/src/ui/hud.js` (`drawUI`,
`drawButtons`) и `catroom/src/input.js` (`onDown`) на 2026-09-08 — если
кнопки/режимы переименуют, текст надо сверить заново.

## План внедрения (не реализовано, только шаги)

1. **Данные.** Добавить массив подсказок в `catroom/src/data.js` (рядом с
   `SUPPLIES_LIST`/`ITEMS_LIST` — тот же файл уже хранит текстовые каталоги
   игры), например `HINTS: [{id, text}]`, текст — из раздела выше.
2. **Экран показа.** Переиспользовать вид панели-заглушки
   (`drawPlaceholderPanel`/`drawSettings` в `ui/hud.js` — те же геометрия
   панели, заголовок, «× закрыть») и добавить в неё пагинацию по образцу
   `drawList` (кнопки ‹ ›/свайп, уже есть для инвентаря) — подсказки длинные,
   на один экран все 15 не поместятся.
3. **Точка входа.** Нужна кнопка, которая открывает подсказки, но по условию
   задачи — не из «Настроек». Открытый вопрос (см. ниже): куда именно её
   поставить.
4. **Триггер первого показа.** Один раз при первом запуске (флаг в
   `localStorage`, как обычно делают для онбординга) показать подсказки
   автоматически, дальше — только по кнопке из п.3. Без этого пункта
   подсказки существуют, но их никто не увидит, пока не найдёт кнопку.
5. **(Опционально, отдельная задача)** контекстные мини-подсказки — например,
   при первом открытии «Инвентаря» показать всплывающую строку с текстом
   подсказки №1, а не только в общем списке. Это уже другой механизм
   (привязан к событию, не к общему экрану), закладывать в п.1–4 не нужно.
